# Auxin Signalling Models

A package and scripts for generating ODE-based models of auxin gene regulatory networks.

## Description

Genetic regulatory networks (GRNs) play an important role in dictating a plant
cell's response to changes in auxin concentration. These sub-cellular mechanisms
underpin lots of plant physiology, such as plant growth. This repository
contains a python package, scripts and jupiter notebooks which generate
mathematical, ODE-based models of auxin GRNs, and compile performant code for
simulations nad statistical analysis.

## Getting Started

### Dependencies

The following installation instructions assume an environment with Python (version >= 3.10) and pip installed. The code has been tested under a Linux (Ubuntu) environment.

#### Requirements for notebooks
There are additional requirements for the jupyter notebooks found in `notebooks`. These are listed in `requirements.txt`

### Installing

First generate and activate fresh virtual environment, `.venv`:
```
python3 -m venv .venv
activate .venv/bin/activate
```

Then install the necessary packages

```
python3 -m pip --upgrade pip
python3 -m pip install -e '.[test]'
```

### Documentation
Documentation can be generated by install sphinx:
```
python3 -m pip install sphinx
```
and running
```
make html
```

This will build the documentation as a website.

### Running code
Tests can be run by entering
```
python3 -m pytest
```

#### Optional myokit model generation
To enable myokit model generation, the package must be installed with the `myokit` optional dependencies like so,

```
pip install '.[myokit]'
```

You may need to follow the instructions to install myokit [myokit.org/instll](myokit.org/install).

#### Jupyter notebooks
Various example Jupyter notebooks are provided in `notebooks`.

To run a notebook, first install the package as above but with the `[notebook]` dependencies.

```
python3 -m venv .venv
activate .venv/bin/activate
python3 -m pip --upgrade pip
python3 -m pip install -e '.[test,notebook]'
```
Then create and install a new kernel
```
python3 -m ipykernel install --user --name auxin_signalling_models_kernel
```

Then run

```
jupyter-notebook notebooks
```

Open a notebook and select the `auxin_signalling_models` kernel in the drop-down menu: Kernel -> Change Kernel.

You can then run the notebook by selecting Cell -> Run All in the drop-down menu.
